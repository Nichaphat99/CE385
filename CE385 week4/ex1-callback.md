1. สร้างข้อมูลนักศึกษา
    const students = [ ... ]
ส่วนนี้เป็นการสร้าง array สำหรับเก็บข้อมูลนักศึกษา แต่ละคนมีข้อมูล คือ
id - รหัสนักศึกษา name - ชื่อ
major - สาขาวิชา score - คะแนน
ใช้ const เพราะเราไม่ได้เปลี่ยนตัว array students ไปเป็น array อื่น

2. ฟังก์ชัน fatchStudentById
    function fetchStudentById(id, callback) { .. }
มีหน้าที่ค้นหานักศึกษาจากรหัส id
รับค่ามา 2 ตัว id - รหัสนศ. 
            callback - ฟังก์ชันจะทำงานหลังค้นหาเสร็จ

3. ตรวจสอบรหัส
ตรวจว่า id ที่ส่งเข้ามาเป็น string หรือไม่
    เช่น 65001 เป็น string = ผ่าน 
แต่ 
    42 เป็น number = ไม่ผ่าน
หากไม่ผ่านจะสร้าง error
ื   new Error ("รหัสนักศึกษาไม่ถูกต้อง")
แล้วส่ง error เข้า callback
    callback(error)
จากนั้น return; เพื่อหยุดฟังก์ชันทันที

4. จำลองการค้นหาข้อมูล 300ms
    setTimeout(() => { 
    }, 300);
โจทย์ต้องการให้จำลแงดึงข้อมูล โดยมีความล่าช้า 300 มิลลิวินาที
จึงใช้ setTimeout

5. ค้นหานักนศ.
    const student = students.find(
    (student) => student.id === id );
ใช้ .find() เพื่อค้นหาข้อมูล array student
เช่น 
    fetchStudentById("65001", ...)
โปรแกรมจะค้นหานศ.ที่มี id === "65001"
ถ้าเจอก็จะเก็บข้อมูลนักศึกษาคนนั้นไว้ในตัวแปร student

6. กรณีค้นหาไม่เจอ
    if (!student) {
    callback(new Error(`ไม่พบรหัสนักศึกษา ${id}`));
    return; }
ถ้า .find() หาไม่เจอ ตัวแปร student จะไม่มีข้อมูล
จะส่ง Error กลับไป เช่น ไม่พบรหัสนักศึกษา 99999
แล้ว return เพื่อหยุดการทำงาน

7. กรณีค้นหาเจอ
    callback(null, { ...student });
ตรงนี้คือหัวใจของ Error-first Callback
ถ้าทำงานสำเร็จ จะส่ง callback(null, student)
    โดยตัวแรกต้องเป็น null เพราะ ไม่มี Error
    ส่วนตัวที่สองคือข้อมูลนักศึกษา { ...student }
หมายถึงการสร้าง สำเนาของ Object นักศึกษา แทนที่จะส่ง Object ต้นฉบับออกไปโดยตรง

8. การเรียกกรณีที่ 1 — มีข้อมูล
เช่น กรณีนี้รหัส 65001 มีอยู่จริง
ดังนั้น error จะเป็น null
และ student จะมีข้อมูลนักศึกษา จึงแสดงข้อมูลออกมา

9. การเรียกกรณีที่ 2 — ไม่มีข้อมูล
เช่น รหัส 99999 ไม่มีใน Array
จึงเกิด Error
    ไม่พบรหัสนักศึกษา 99999
และเข้า if (error) เพื่อจัดการ Error

10. การเรียกกรณีที่ 3 — รหัสผิดรูปแบบ
    fetchStudentById(42, (error, student) => { .. } )
ตรงนี้ส่ง 42 เข้าไป ซึ่งเป็น Number ไม่ใช่ String
จึงไม่ผ่านเงื่อนไข
    typeof id !== "string"
และได้ รหัสนักศึกษาไม่ถูกต้อง
