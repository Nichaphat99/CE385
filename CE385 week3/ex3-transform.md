//สร้างข้อมูลนักศึกษา
ส่วนนี้เป็นการสร้างตัวแปร students ซึ่งเป็น Array ที่ใช้เก็บข้อมูลนักศึกษาหลายคน โดยแต่ละคนจะเก็บข้อมูลเป็น Object ได้แก่ รหัส ชื่อ สาขา คะแนน และข้อมูลติดต่อ



//getNames() — ดึงชื่อของนักศึกษาทุกคน
ฟังก์ชันนี้ใช้สำหรับ ดึงเฉพาะชื่อของนักศึกษาทุกคนออกมา
โดยใช้ map() เพราะเราต้องการนำข้อมูลจากนักศึกษาแต่ละคนมาแปลงให้เหลือเฉพาะ name

เช่น จากข้อมูล
{
    id: "1001",
    name: "สมชาย ใจดี",
    major: "CE"
}
เราต้องการแค่ สมชาย ใจดี ดังนั้นผลลัพธ์ของ getNames() จะเป็น Array ของชื่อทั้งหมด
map() เหมาะกับการเอาข้อมูลแต่ละตัวมาแปลงเป็นรูปแบบใหม่



//getPassedStudents() — หาคนที่สอบผ่าน
ฟังก์ชันนี้ใช้สำหรับ ค้นหานักศึกษาที่สอบผ่าน
โดยกำหนดว่า ถ้าคะแนนมากกว่าหรือเท่ากับ 50 จะถือว่าสอบผ่าน
student.score >= 50
ตรงนี้ใช้ filter() เพราะเราต้องการคัดเฉพาะนักศึกษาที่ตรงตามเงื่อนไข

เช่น ถ้ามีคะแนน
75 → ผ่าน
85 → ผ่าน
48 → ไม่ผ่าน
65 → ผ่าน
52 → ผ่าน
90 → ผ่าน
ผลลัพธ์จะเหลือเฉพาะคนที่คะแนน >= 50
filter() ใช้สำหรับกรองข้อมูลตามเงื่อนไข



//getTotalScore() — หาคะแนนรวม
ฟังก์ชันนี้ใช้สำหรับ หาคะแนนรวมของนักศึกษาทุกคน
ตรงนี้ใช้ reduce() เพราะเราต้องการนำคะแนนหลาย ๆ ตัวมารวมกันให้เหลือเป็น ค่าหนึ่งค่า

ส่วนนี้ total + student.score
หมายถึงเอาคะแนนของนักศึกษาแต่ละคนมาบวกสะสมไปเรื่อย ๆ

ส่วน }, 0);
เลข 0 คือ ค่าเริ่มต้นของ total

ตัวอย่างเช่นคะแนน
75 + 85 + 48 + 65 + 52 + 90
ก็จะได้คะแนนรวมทั้งหมด

reduce() ใช้สำหรับรวมข้อมูลหลายตัวให้เหลือเป็นค่าหนึ่งค่า



//getAverageScore() — หาคะแนนเฉลี่ย
ฟังก์ชันนี้ใช้สำหรับ คำนวณคะแนนเฉลี่ยของนักศึกษาทั้งหมด
ก่อนคำนวณจะตรวจสอบก่อนว่า Array มีข้อมูลหรือไม่

ถ้าไม่มีนักศึกษาเลย จะคืนค่า 0
เหตุผลที่ต้องตรวจสอบก่อน เพราะถ้าเอา 0 ไปหารด้วย 0 จะได้ NaN
ซึ่งโจทย์กำหนดว่า ถ้า Array ว่างต้องไม่ให้เป็น NaN

ถ้ามีข้อมูล ก็จะใช้
getTotalScore(students) / students.length
คือ คะแนนรวม ÷ จำนวนคน = คะแนนเฉลี่ย



//countByGrade() — นับจำนวนคนแยกตามเกรด
ฟังก์ชันนี้ใช้สำหรับ นับว่านักศึกษาแต่ละเกรดมีกี่คน
ตรงนี้ใช้ reduce() เพราะเราต้องการรวบรวมข้อมูลทั้งหมดให้กลายเป็น Object เดียว

การกำหนดเกรด
เช่น if (student.score >= 80) {
    grade = "A";}
ถ้าคะแนนตั้งแต่ 80 ขึ้นไป จะได้เกรด A

result[grade] = (result[grade] || 0) + 1;บรรทัดนี้ใช้สำหรับ นับจำนวนของแต่ละเกรด

ถ้ายังไม่มีเกรดนั้น result[grade] จะไม่มีค่า จึงใช้ || 0
ให้เริ่มต้นที่ 0 แล้วบวก 1

เช่น ถ้าเจอ A คนแรก:
A = 0 + 1
A = 1

ถ้าเจอ A อีกคน:
A = 1 + 1
A = 2

ส่วนท้าย }, {});
หมายถึงกำหนดค่าเริ่มต้นของ reduce() เป็น Object ว่าง {}



//getTopStudent() — หาคนที่คะแนนสูงสุด
ฟังก์ชันนี้ใช้สำหรับ ค้นหานักศึกษาที่มีคะแนนสูงสุด

โจทย์กำหนดให้ใช้ reduce()
แนวคิดคือให้ top เป็นนักศึกษาที่มีคะแนนสูงสุดที่เราเจอในตอนนั้น แล้วนำไปเปรียบเทียบกับ student คนถัดไป

if (student.score > top.score)
ถ้านักศึกษาคนปัจจุบันคะแนนมากกว่า top ก็ให้เปลี่ยน top เป็นคนปัจจุบัน
สุดท้ายจะเหลือ Object ของนักศึกษาที่ได้คะแนนสูงสุด

//ส่วนที่ 2 — CE ที่สอบผ่าน
ขั้นแรกใช้ filter() เพื่อเอาเฉพาะนักศึกษาสาขา CE
.filter(student => student.major === "CE")

จากนั้น filter() อีกครั้งเพื่อเอาเฉพาะคนที่สอบผ่าน
.filter(student => student.score >= 50)

ดังนั้นตอนนี้ cePassedStudents จะเหลือเฉพาะนักศึกษาสาขา CE ที่คะแนนตั้งแต่ 50 ขึ้นไป



//ใช้ map() เอาเฉพาะคะแนน

เช่น
[
    { name: "สมชาย", score: 75 },
    { name: "ปิติ", score: 52 }
]
จะกลายเป็น[75, 52]



//ใช้ reduce() หาค่าเฉลี่ย
